# 🎬 Cinema System — Kinoteatr boshqaruv tizimi

## 📌 Project haqida
Ushbu loyiha Python dasturlash tilida OOP (Object-Oriented Programming)
tamoyillari asosida yaratilgan kinoteatr chipta tizimidir.

Foydalanuvchilar afishani ko'rishi, zal sxemasini ko'rishi, o'rindiq tanlab
chipta sotib olishi, chiptani bekor qilishi va tarixni ko'rishi mumkin.

## 🎯 Project maqsadi
Python'dagi Class va Object mavzularini amaliyotda qo'llash hamda OOP
tamoyillarini mustahkamlash.

## ⚙️ Asosiy imkoniyatlari
- Ism orqali tizimga kirish.
- Bugungi afishani ko'rish.
- Zal sxemasini (band / bo'sh o'rindiqlar) ko'rish.
- Chipta sotib olish.
- Chiptani bekor qilish.
- Chiptalar tarixini ko'rish.
- Tizimdan chiqish.

## 🧩 Ishlatilgan texnologiyalar
Python 3, OOP, Classes & Objects, Constructor (`__init__`), Methods,
Encapsulation (private `__seats`, `__movies`, `__tickets`),
Lists & Dictionaries, Conditional Statements, Loops.

## 📁 Project structure
```
Cinema_Project/
├── main.py
├── movie.py
├── cinema.py
├── ticket.py

```

## 🏗️ Classlar vazifasi
1. **Movie** — film ma'lumotlari va zal o'rindiqlarini boshqaradi.
2. **Cinema** — asosiy funksiyalar, menyu va foydalanuvchi bilan ishlash.
3. **Ticket** — sotib olingan chiptalarni saqlaydi va tarixni ko'rsatadi.

```
python main.py
```
